# Chinese Queer Corpus (CQC) — website

Public website of the Chinese Queer Corpus: https://chinesequeercorpus.github.io/cqc/

This repository contains **only the website**. No corpus data, audio, transcripts, TextGrids, or speaker metadata are stored here. Access to the corpus data is available to researchers under the [CQC Data Use Agreement](https://chinesequeercorpus.github.io/cqc/agreement.html).

Contact: chinesequeercorpus@outlook.com
